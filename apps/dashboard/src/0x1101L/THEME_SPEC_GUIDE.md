# Dashboard 테마 규격

이 안내서는 새 테마의 화면과 디자인 결정을 정한다. 테마를 만들기 전 [생성 질문표](../../../../docs/THEME_CREATION_QUESTIONNAIRE.md)를 작성하고, JSON 파일 형식과 로딩 동작은 [테마 엔진 v3 규격](../../../../docs/theme_engine_v3.md)을 따른다. 이 문서는 개발 안내서이며 앱 리소스로 패키징되지 않는다.

## 화면의 고정 조건

Overview는 **5열×4행, 20개 항목이 한 화면에 보이는 구성**이다. 테마, 시안, 프리뷰 모두 이 규칙을 따른다. 4×3을 비롯한 다른 격자와 이전·다음 버튼, Overview 페이징은 만들지 않는다.

새 독립 테마는 Original을 상속하지 않는다. 필요한 색, 표면, 글꼴과 레이아웃을 자체 테마 번들에 선언한다. 기존에 부모 테마를 명시한 파생 테마의 관계는 별도 요청 없이 바꾸지 않는다.

테마는 표현을 맡는다. 차량 신호의 의미와 계산, 단위, 경고·무효·미수신 판정, 조작 방식과 기존 설정 저장 의미는 바꾸지 않는다. 런타임에서 지원하지 않는 JSON 속성도 추가하지 않는다.

## 엔진별 디자인 방향

| 테마 계열 | 참고할 원칙 | 적용 범위 |
|---|---|---|
| Material Auto | Google Material 3의 색 역할과 key color 접근. Android Auto 공식 자료의 차량 화면 판독성·명확한 계층. | 독립된 Material 기반 테마. Android Auto 인증 화면으로 표현하지 않으며 투사 앱의 dp 값을 800×480 좌표에 그대로 옮기지 않는다. |
| Liquid Glass | Apple HIG의 재질 원칙. Glass는 제어·탐색 표면, wallpaper는 콘텐츠 배경이다. | Glass 효과는 런타임에 그리고 이미지에는 합성하지 않는다. |
| Original | 기존 기본 화면의 기준선. | 새 테마의 상속 기반으로 사용하지 않는다. |

포인트 컬러는 엔진별 팔레트에서 선택한다. 선택 가능한 primary 색은 바꿀 수 있지만 경고·위험·미수신 색과 기존 상태 표기는 유지한다. 상태를 색 하나만으로 전달하지 않는다.

## Liquid Glass 배경 선택

Apple HIG는 Liquid Glass용 팔레트별 wallpaper 세트를 규정하지 않는다. 이 프로젝트의 팔레트별 이미지는 기존 Liquid Glass 배경의 곡선과 밝기를 잇는 전용 콘텐츠 아트다. 원본 배경은 보존하고 새 자산을 별도 파일로 추가한다. 기준 문구와 파일명은 [배경 이미지 프롬프트](../../../../docs/LIQUID_GLASS_WALLPAPER_PROMPTS_20261119.md)에 기록한다.

| 사용자의 배경 설정 | 포인트 컬러를 바꿨을 때 |
|---|---|
| 테마 기본값 | 해당 Liquid Glass 팔레트의 기본 배경을 표시한다. |
| 직접 고른 배경 | 선택을 유지한다. 포인트 컬러로 덮어쓰지 않는다. |
| 직접 선택에서 테마 기본값으로 복귀 | 현재 팔레트에 대응하는 배경으로 돌아간다. |

이 동작은 Liquid Glass에만 적용한다. `accentBackgrounds` 같은 연결은 런타임·설정·프리뷰·fallback·테스트가 갖춰지기 전까지 미구현이다. 구현 전에는 v3 JSON에 지원되지 않는 키를 추가하지 않는다.

## 제작과 검수

질문표에서 화면, 엔진, 팔레트, 메뉴와 배경을 결정한 뒤 고유 ID의 테마 번들을 만든다. 신규 독립 테마는 부모 없이 선언하고 catalog에 등록한다. 공용 JSON 속성을 새로 도입한다면 schema, parser, `ThemeSpec`, 오류 시 기본 동작과 테스트를 함께 변경한다.

800×480에서 5×4 Overview, F1, 메뉴·독, 긴 한글, 숫자·단위, 신호 상태와 낮·밤 대비를 살핀다. 테마 적용·취소, wallpaper 기본값 복귀와 직접 선택 유지도 확인한다. 프리뷰, 호스트 테스트, Android 빌드와 실기기 결과를 구분해 기록한다.
